Hardware & Software

Every computer system is built from two things working together: the physical parts you can touch, and the instructions that tell those parts what to do. This page walks through both, plus how computers turn the analogue world into the 1s and 0s they actually understand.

Hardware Software Operating systems Analogue & digital

Hardware the physical parts

Hardware means the physical components of a computer system — anything you could physically pick up or point to. Hardware falls into three groups:

Internal components

  • CPU (Central Processing Unit) — the "brain" of the computer, made up of processors that carry out instructions
  • Motherboard — the circuit board that connects every important component together so they can communicate

Internal memory

  • RAM (Random Access Memory) — fast, working memory. Its contents are lost when the power is switched off
  • ROM (Read-Only Memory) — holds the instructions the computer needs to start up, and keeps them even without power

Hardware components

  • Graphics card (GPU) — processes images and video
  • Sound card — processes audio
  • Network Interface Card (NIC) — provides a wired connection to a network
  • Camera — captures images or video
  • Storage devices — store data permanently, e.g. a hard drive or USB stick
  • Input devices — let the user put data in, e.g. mouse and keyboard
  • Output devices — show the results of processing, e.g. a monitor

Software

Software is the set of programs that control the hardware. It lives on the computer system but can't be physically touched. Software splits into two categories: application software and system software.

Application software

Application software (often just called "apps") is chosen by the user to carry out a specific task. It's installed on top of system software. Common categories:

  • Word processing — creating and editing text documents
  • Spreadsheet — organising and analysing data in a grid
  • Database management — storing, retrieving and managing data
  • Control / measurement — using sensors to measure and control a system
  • Video, graphics and audio editing — creating and modifying media files
  • Computer-Aided Design (CAD) — designing and modelling objects in 2D or 3D

System software

System software is essential for the computer to run at all — without it, there's no starting point for giving the computer instructions. It gives the user a platform to run applications. Key examples:

  • Compilers — translate high-level programming languages into machine code
  • Linkers — combine object files into a single executable program
  • Device drivers — control hardware components and peripherals
  • Operating systems — manage the computer's resources and provide a user interface
  • Utilities — tools for maintaining and optimising performance

Common mix-up: control software sounds technical, but it's actually application software, not system software — it's chosen by a user for a specific job.

Operating systems and user interfaces

An operating system (OS) is software that provides an interface between the user and the hardware. It makes a computer usable by:

  • Controlling input/output devices
  • Overseeing the loading, running and storage of application software
  • Dealing with errors
  • Maintaining security
  • Keeping a log of events

User interfaces

A user interface is how the user interacts with the operating system. There are four main types:

InterfaceHow users interactExample
Command Line (CLI)Typed text-based commandsMS-DOS, Raspbian terminal
Graphical (GUI)Visual elements — windows, icons, menus, pointersWindows, macOS
Dialogue-basedSpoken wordAmazon Alexa, Siri
Gesture-basedHuman movement — hands, fingers, head, feetSmartphones (swipe, pinch, zoom)

CLI trades ease of use for control: it uses fewer resources and is great for automation, but you need to remember exact commands. GUI is intuitive and visual, but uses more resources and can feel slow for repetitive tasks.

Analogue & digital data

Analogue data is continuous — it changes gradually and smoothly, and it's produced by non-digital devices. Sound waves and raw sensor readings are analogue. Digital data is represented in binary (1s and 0s), and it's what computers actually create and store — documents, software, files.

Analogue-to-digital conversion (ADC)

Sensors produce analogue output, but computers can only process digital data — so it has to be converted. ADC works by taking samples (measurements) of the analogue signal at regular intervals and converting each one to a binary code. A higher sample rate and more binary digits give a more accurate result, but take up more storage space.

Digital-to-analogue conversion (DAC)

To control real-world analogue devices (like a motor or a speaker), digital data has to be converted back into a continuous analogue signal. The quality of that signal depends on the original sample rate and number of bits used.
